Principles

四条设计底线

决定了系统为什么长成现在这样。

upstream

不改上游源码

上游 Semantica 0.7.0 的 src/ 保持原样，定制以启动包装、构建期补丁、独立侧车三种形式叠加，升级不痛。

storage

图谱落在 Neo4j

摆脱“整张图在进程内存里”的规模限制，界面退化为定期刷新的只读副本。

agent

智能体只走侧车

独立容器承担协议适配、工具语义、鉴权限流与审计，上线回滚不动 Explorer。

auth

两套凭据域

人用 Basic Auth，机器用 Bearer；令牌只在 /mcp 生效，浏览器永远拿不到 API Key。

readonly

只读副本保护

Neo4j 为主库时 Explorer 写接口 403，写入统一收敛到 MCP 与接入作业。

offline

完全离线部署

镜像与 Python wheel 带哈希锁定，内网无外网也能构建，密钥只留在状态根。

Quick Start

五分钟上手

四个入口，对应四类使用者。

打开 Explorer 看图谱

访问 http://10.100.0.69:18835，用团队账号登录，在“图谱浏览”里搜索实体名称或编号。

在 JupyterLab 跑抽取

访问 :18836，打开 examples/01_文档抽取，或用 semantica_lab.push() 推送自己的结果。

向合同专家提问

访问 :18180 进入 Chat 页，带编号提问最准，例如“HT-2022-0001 和 DW-0001 是什么关系？”。

用 MCP 接入自己的程序

向运维申请客户端令牌，POST 到 :18835/mcp，先调 graph_schema 再写查询。
